# FirstPromoter

**Affiliate and referral management software for SaaS companies.** Track referrals and commissions from your billing provider, run affiliate, referral and influencer programs from one platform, and pay your partners.

[Website](https://firstpromoter.com) · [Docs](https://docs.firstpromoter.com) · [Help center](https://help.firstpromoter.com/en/) · [Changelog](https://changelog.firstpromoter.com/) · [Careers](https://firstpromoter.com/careers)

## Build with FirstPromoter

| | |
|---|---|
| [REST API v2](https://docs.firstpromoter.com/api-reference-v2/api-admin/introduction) | Manage promoters, campaigns, referrals, commissions and payouts from your own code. |
| [Webhooks](https://docs.firstpromoter.com/webhooks-v2/overview) | Get notified about events in your affiliate program. |
| [fpr.js tracking script](https://docs.firstpromoter.com/script-docs/fpr-js-docs) | Track referral visits, sign-ups and sales on your website. |
| [MCP server](https://docs.firstpromoter.com/mcp/overview) | Connect AI clients like Claude and ChatGPT to your FirstPromoter account (experimental). |
| [Automation](https://docs.firstpromoter.com/automation/n8n-node) | Build workflows with the [n8n node](https://docs.firstpromoter.com/automation/n8n-node), [Zapier](https://docs.firstpromoter.com/automation/zapier) or [Make](https://docs.firstpromoter.com/automation/make). |

- **Billing:** [Stripe](https://docs.firstpromoter.com/integrations/billing/stripe), [Chargebee](https://docs.firstpromoter.com/integrations/billing/chargebee), [Paddle](https://docs.firstpromoter.com/integrations/billing/paddle), [Recurly](https://docs.firstpromoter.com/integrations/billing/recurly), [Braintree](https://docs.firstpromoter.com/integrations/billing/braintree), or [any provider via the API](https://docs.firstpromoter.com/integrations/billing/api).
- **Payouts:** [Tipalti](https://docs.firstpromoter.com/integrations/payouts/tipalti) and [Wise](https://docs.firstpromoter.com/integrations/payouts/wise).
- See all [integrations](https://firstpromoter.com/integrations).
